# Jump

> 一个专门用来整蛊别人的网站重定向页面。

## 这是什么

别被这个名字骗了——它不是游戏，也不是什么正经网站。

当有人点开你分享的链接，页面不会说任何多余的话，而是直接把人带走：跳转到恶搞内容（比如经典 Rickroll）。对方满怀期待地点进来，然后一脸问号地被"整"了。

全程没有提示、没有铺垫，主打一个猝不及防。

## 玩法

1. 拿到页面链接后，发给你的朋友（或者丢进群聊）。
2. 配上一句让人无法拒绝的诱饵文案，比如：
   - "快看这个，笑死我了"
   - "你要的资料在这里"
   - "帮我看看这个链接打不开"
3. 坐等对方的反应。

一次成功的整蛊，通常以对方发来一句"？？？"或"你等着"结束。

## 适用对象

- 群聊里爱发奇怪链接的朋友
- 总是催你发资料的人
- 嘴上说"什么都吓不到我"的人

（请自行评估对方脾气，后果自负。）

本项目仅供娱乐，请勿用于任何恶意用途。

- 不要用它伪装钓鱼链接，骗取账号、密码或隐私信息；
- 不要用于骚扰、诈骗或其他违法行为；
- 整蛊有度，玩笑别开过头，朋友比乐子重要。
